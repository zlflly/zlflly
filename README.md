- **额度显示：** [`@llblab/pi-codex-usage`](https://www.npmjs.com/package/@llblab/pi-codex-usage)
- **子代理与工作流：** [`@kky42/pi-flow`](https://www.npmjs.com/package/@kky42/pi-flow)
- **自动会话命名：** [`@moguw/pi-session-rename`](https://www.npmjs.com/package/@moguw/pi-session-rename)
  - 第一轮对话后命名，之后每轮更新
  - 使用 `gpt-5.6-luna`，Low thinking
- **主题：** `omarchy-system`
